# 原稿一

中医不赞成早餐吃冷酸奶，我来解释一下原因。在中医里，酸奶被认为是偏寒、偏湿的食物。寒会减慢消化，湿则会带来沉重感和腹胀。

中医常把胃比作一口锅。早晨，这口锅才刚刚开始升温。如果你放进去的第一样东西是酸奶这样的冷食，就像往锅里倒了一盆冷水。温度降下来后，锅里的火得先花更多力气把它重新烧热，而不是直接烹煮食物，消化也会随之慢下来。

这也是为什么传统的中式早餐通常是温热、煮熟的食物，比如粥、鸡蛋、汤或面条。目的在于帮助消化，而不是一大早就给它一次寒凉刺激。

如果消化长期比较弱，有些人会开始出现腹胀、脑子发蒙、便溏、饭后精力不足，或者体重一直难以下降。有些人吃酸奶完全没问题，这也很正常。但如果你本来就有消化方面的困扰，早晨吃冷酸奶往往会让这些感受更明显。

不妨换个方式，让这口锅先暖起来。早餐吃熟食、温热的食物，或者早晨先喝一点温水。连续做一周，看看身体有什么感受。

# 原稿二

中医怎么看希腊酸奶？它算是一把双刃剑。它当然有一定的营养，但从中医角度看，它也是一种可能在不知不觉中影响消化的食物。

希腊酸奶被认为偏寒，而且容易生湿。在中医里，“寒”不只指食物摸起来的温度，也表示它可能减慢身体内部的代谢，就像把冰水浇在消化之火上。这样一来，负责消化和提供能量的脾胃之气就会变弱，人也可能开始在饭后感觉腹胀、疲惫或身体沉重。

酸奶属于乳制品，在中医里也被认为容易生痰。有些人可能会感觉喉咙黏、鼻窦堵塞，甚至更容易长痘。因此，如果你很容易腹胀，或者长期受到痰多、鼻窦问题的困扰，中医的建议可能是先不吃它。

但如果你很喜欢希腊酸奶，并不想放弃，可以试试这个中医搭配方法：先把酸奶放到室温，再搭配温热、对脾比较友好的食物，比如炖梨、煮苹果、核桃或枸杞。这样的组合可以平衡酸奶的寒凉属性，让身体更容易接受。

# 当前成稿

如果你早餐吃完冷酸奶容易腹胀或疲惫，中医的这个视角或许能解释原因。我正在中国学习中医师承，下面用日常语言把它讲清楚。

你可以把胃想成一口早晨刚开始升温的锅。第一口吃进去的是冷酸奶，这口锅就得先重新升温，才能继续消化。在中医里，酸奶也被归为偏寒、偏湿的食物。对于本来消化就比较弱的人，这可能表现为腹胀、便溏、脑子发蒙、饭后没精神，或者身体有沉重感。

希腊酸奶还多一层需要观察的地方。它有营养，但对于本来就容易喉咙黏、鼻窦堵塞或长痘的人来说，乳制品也可能让身体出现更多“痰湿”的感觉。这并不表示所有人都要戒掉酸奶，有些人吃了完全没问题。

如果你想继续吃酸奶，可以先放到室温，再搭配煮苹果、炖梨、核桃或枸杞这类偏温暖的食物。也可以连续七天改吃熟的早餐，比如热粥、鸡蛋、汤、面条、热包子或温豆浆。在传统的子午流注框架里，早上七点到九点被认为是胃和脾尤其活跃的早餐时段。

关注我，我会继续把中医翻译成日常生活里能用的饮食方法。
